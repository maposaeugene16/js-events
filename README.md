## 💻 Tech Stack & Architecture

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS with custom brand gold and emerald palettes
- **Icons:** Lucide React
- **Performance:** Optimized local image rendering with static prerendering
- **Interactive Features:**
  - **Floating WhatsApp Widget:** Click-to-chat popup with quick inquiry templates and online indicator.
  - **Interactive Quote Calculator:** Select event type, guest slider, equipment checklist, and instant WhatsApp message generation.
  - **Equipment Catalog with Cart:** Add chairs, tents, and chafers to a hire list and send straight to WhatsApp.
  - **Dynamic Gallery:** Filterable showcase with full-screen lightbox previews.
  - **Mobile Responsive:** Designed mobile-first for fast loading across smartphones in Zimbabwe.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested with Node.js v20.18.0)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/js-events.git
cd "JS Events"

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the website.

### Production Build

```bash
npm run build
npm start
```
